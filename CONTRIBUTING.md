# Contributing Guide 🎓

We're thrilled that you want to help with UniMySQL-MCP! This is an educational project, and all hands are welcome.

## How can you help?
- **Reporting Bugs:** If something isn't working, open an Issue.
- **Suggestions:** Have an idea for a new educational tool? Let us know!
- **Code:** If you want to fix something or add a feature, open a Pull Request.

## Steps to collaborate
1. Fork the project.
2. Create a branch for your improvement (`git checkout -b feature/my-improvement`).
3. Make your changes and ensure the code remains "human" and easy to read.
4. Open a Pull Request.

Thanks for being part of the community! 🚀
